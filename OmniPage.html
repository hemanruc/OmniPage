OmniPage 功能介绍

您的个人导航主页使用指南

⭐ 已收藏

1收藏本页为书签

建议将本页添加为浏览器书签，方便随时访问：

  • Chrome / Edge：按 Ctrl+D（Windows）或 Cmd+D（Mac），选择书签栏保存
  • Firefox：按 Ctrl+D，选择「书签工具栏」保存
  • Safari：按 Cmd+D，选择「个人收藏夹」

💡 提示：您也可以将本页设为浏览器启动主页，每次打开浏览器即可直达。

2融合搜索

页面顶部是融合搜索框，输入关键词后点击「搜索」即可跳转。

支持切换不同搜索引擎：夸克、必应、谷歌、淘宝、京东。点击标签即可切换默认引擎。

💡 提示：按回车键可直接触发搜索。

3分类导航

左侧固定导航栏列出所有分类，点击即可平滑滚动到对应板块。

滚动页面时，左侧导航会自动高亮当前所在分类（滚动监听）。

每个分类标题前都有主题色竖条标识，简洁醒目，风格中性百搭。

↕️

4编辑模式

点击左侧「编辑」按钮进入编辑模式，此时：

  • 每个链接卡片变成可编辑表单，可直接修改名称、URL、备注、关键词
  • 拖拽链接卡片可调整同一分类内的顺序
  • 点击 ↑ ↓ 箭头可调整分类顺序
  • 点击「➕ 添加链接」可在该分类下新增条目
  • 点击「添加新分类」可创建全新板块

✏️ 修改完成后，点击「保存」写入浏览器本地存储；点击「取消」放弃修改。

5导入与导出

数据完全保存在您本地，支持备份与迁移：

  • 导出：生成 JSON 或 TXT 格式文件下载到电脑，建议定期备份
  • 导入：上传之前备份的 JSON 文件，或粘贴 JSON 文本，即可恢复全部数据

🔒 数据仅存储在浏览器 localStorage 中，不会上传到任何服务器。

6链接检查

点击左侧「检查链接」按钮，系统会批量检测所有 URL 的可达性。

检测完成后，失效链接的卡片右上角会显示红色小圆点，方便您及时清理或更新。

⚠️ 注意：部分网站可能因反爬虫机制被误判，请结合实际情况判断。
